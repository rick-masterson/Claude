Skill Wizard

Build a portable SKILL.md with a bench of models. Every AI step runs on all active models at once: compare their drafts, keep one, or let a judge merge them. Then have every model review the result.

Model bench

Tick the models to spawn on. Inside Claude needs no key but only works when this page runs inside Claude. The others call the provider straight from your browser with your key: Anthropic, OpenAI, OpenRouter, Gemini, or any OpenAI-compatible server such as Ollama or LM Studio. Keys stay in this page's memory unless you choose to remember them. Your skill text is sent to every active model, so only tick providers you trust with it.

Identify the skill

Short and specific. It becomes the folder name and the name: field: lowercase letters, digits and hyphens, at most 64 characters.

→ folder: your-skill/SKILL.md

Wire the triggers

Phrases or situations that should make an agent reach for this skill. They are added to the description, which is the only part every session loads.

Write the instructions

What the agent reads when the skill fires: steps, commands, checklists. Only what a capable agent would not already know, and no single agent's tool names, so any model can follow it.

Assemble

The full file, checked against the open Agent Skills spec and for injection patterns that model output can carry.

    Cross-review

    Every active model reviews the finished SKILL.md independently. The judge then applies the fixes that matter, and you compare before keeping them.

    → your-skill/SKILL.md
    Name the skill in step 1 to start assembling.
